# 📝 抄写助手

## 为什么做这个工具？

作为一个高二牲，我每次抄写长作文的时候，总是抄着抄着就串到别的行去了，然后又要重新找回位置，抄着抄着又看错了，特别烦人。于是干脆用AI写了一个网页，让屏幕一次只显示当前这一句，左右点击就能翻页，再也不会抄串行。改了好几版，终于满意了

现在把它分享出来，希望能帮到和我一样需要抄写长文的朋友。

## ✨ 功能特点

- 📐 自定义每行字数（5~100 字），字号自动适配屏幕宽度
- 👆 电脑上鼠标点击左右半屏翻行，手机上触摸左右区域翻行
- ⌨️ 键盘方向键 ← → 或空格键都能翻行
- 🟢 进入新段落时会有绿色提示，防止段落间抄漏
- 📊 底部可拖动的进度条，绿色标记固定显示段落起始位置
- 🌗 护眼深色主题，横屏竖屏自适应
- 📱 全面支持移动端安全区域与触摸操作

## 🚀 使用方法

1. 打开网页
2. 粘贴你要抄写的作文或文章
3. 调整“每行字数”到你喜欢的长度，点击“开始”
4. 从第一句开始，看着屏幕抄就行

## 📝 更新日志

### 2026-07-25 · 新增记忆功能 + 修复 6 个 Bug

**✨ 新增：记忆功能**

关闭网页再打开，文本和上次抄到哪里都会自动恢复，不用重新粘贴、不用重新找位置。

- 自动保存：输入文本、阅读进度（行号）、每行字数、行距、按钮显示状态
- "开始"按钮会变成 `继续 (第 X 行)`，旁边多出 `从头开始` 一键回到第一句
- 输入框下方显示 `↻ 已记忆 MM/DD HH:MM · 第 X 行` 绿色提示，方便确认
- 设置面板新增 `🗑️ 清除记忆` 按钮（带二次确认）
- 防抖保存（500ms）+ 关闭页面前强制保存一次，避免丢失
- 数据存在浏览器本地（localStorage），不上传服务器，换浏览器/清缓存会失效

**🐛 修复的 Bug**

- 修了空文本时段落统计显示 `-Infinity` 的问题
- 修了文本里含 `<` `&` 等符号时显示错乱（潜在 XSS）
- 修了 Windows 换行符 `\r\n` 不能正确分段的问题
- 修了进度条拖到最右端时索引越界
- 修了多次进出阅读模式时事件监听器重复绑定（导致翻页一次翻多行）
- 修了调大每行字数后当前行号可能超出范围
